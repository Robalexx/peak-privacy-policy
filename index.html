🔒 Politique de confidentialité

Dernière mise à jour : 17 janvier 2025

Chez Peak, nous prenons votre vie privée au sérieux. Cette politique de confidentialité explique quelles données nous collectons, comment nous les utilisons et vos droits concernant ces données.

1. Données que nous collectons

1.1 Informations de compte

Lorsque vous créez un compte Peak, nous collectons :

  • Nom d'utilisateur et nom d'affichage
  • Adresse email
  • Mot de passe (stocké de manière sécurisée et chiffrée)
  • Photo de profil (optionnelle)
  • Biographie (optionnelle)

1.2 Contenu créé par l'utilisateur

  • Objectifs et exploits : Titres, descriptions, catégories, durées
  • Publications : Photos et vidéos que vous partagez pour documenter vos progrès
  • Commentaires et interactions : Likes, commentaires, messages
  • Sous-tâches : Étapes de vos objectifs

1.3 Données d'utilisation

  • Données de navigation : Pages visitées, fonctionnalités utilisées
  • Statistiques de progression : Pourcentage de complétion, temps passé
  • Interactions sociales : Abonnements, collaborations
  • Informations techniques : Type d'appareil, système d'exploitation, version de l'app

1.4 Données de localisation

Peak ne collecte PAS de données de géolocalisation.

2. Comment nous utilisons vos données

2.1 Fourniture du service

  • Créer et gérer votre compte
  • Permettre le suivi de vos objectifs
  • Afficher votre profil et vos exploits publics
  • Faciliter les interactions sociales (abonnements, collaborations)

2.2 Amélioration du service

  • Analyser l'utilisation de l'app pour améliorer l'expérience
  • Identifier et corriger les bugs
  • Développer de nouvelles fonctionnalités

2.3 Communication

  • Vous envoyer des notifications liées à vos objectifs
  • Vous informer des interactions sociales (likes, commentaires)
  • Communiquer des mises à jour importantes de l'app

3. Partage de vos données

3.1 Avec d'autres utilisateurs

  • Profil public : Nom d'utilisateur, photo, bio, exploits publics
  • Exploits privés : Visibles uniquement par vous et vos collaborateurs invités
  • Publications : Visibles selon vos paramètres de confidentialité

3.2 Avec des tiers

Nous ne vendons JAMAIS vos données personnelles à des tiers.

Nous partageons des données uniquement avec :

  • Supabase : Notre infrastructure backend pour stocker les données de manière sécurisée
  • Fournisseurs de services cloud : Pour le stockage des médias (photos, vidéos)
  • Services d'analyse : Données anonymisées pour améliorer l'app (Amplitude)

4. Stockage et sécurité des données

4.1 Mesures de sécurité

  • Chiffrement : Toutes les communications sont chiffrées (HTTPS/TLS)
  • Mots de passe : Hachés avec des algorithmes sécurisés
  • Authentification : Système sécurisé avec jetons d'accès
  • Contrôle d'accès : Seules les personnes autorisées peuvent accéder aux données

4.2 Durée de conservation

  • Compte actif : Tant que votre compte est actif
  • Compte supprimé : 30 jours après suppression (pour permettre la récupération)
  • Données anonymisées : Conservées indéfiniment pour statistiques globales

5. Vos droits

Conformément au RGPD, vous avez le droit de :

  • Accès : Accéder à toutes vos données via votre profil
  • Rectification : Modifier vos informations dans les paramètres
  • Suppression : Supprimer votre compte et toutes vos données
  • Portabilité : Demander une copie de vos données au format JSON
  • Opposition : Vous opposer au traitement à des fins de marketing

Pour exercer ces droits

Contactez-nous à : privacy@peak-app.com

6. Données des mineurs

Peak est destiné aux utilisateurs de 13 ans et plus. Nous ne collectons pas sciemment de données d'enfants de moins de 13 ans.

7. Modifications de cette politique

Nous pouvons mettre à jour cette politique de temps en temps. Nous vous informerons des changements importants via notification dans l'app ou par email.

10. Contact
